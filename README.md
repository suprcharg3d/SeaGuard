# SeaGuard – Aplikasi Pelapor Sampah Laut

**SDG 14: Life Below Water**

SeaGuard adalah aplikasi mobile berbasis Android yang bertujuan untuk membantu pelaporan sampah di wilayah pesisir dan laut. Aplikasi ini mendukung pelaporan berbasis lokasi, foto, serta visualisasi data melalui peta.

## Tujuan Proyek

Aplikasi ini dikembangkan sebagai implementasi dari **Sustainable Development Goals (SDG) 14: Life Below Water**, dengan fokus pada pengurangan pencemaran laut melalui pelaporan dan edukasi berbasis teknologi.

---

## Fitur Utama

- Login & Register pengguna  
- Pelaporan sampah dengan foto dan lokasi (GPS)  
- Penyimpanan data menggunakan SQLite (Room)  
- Tampilan detail laporan  
- Peta interaktif berbasis OpenStreetMap (OSM)  
- Halaman edukasi tentang pelestarian laut  

---

## Platform

- Android  
- Bahasa: Kotlin  
- Database: Room (SQLite)  
- Peta: OpenStreetMap (OSMDroid)

## Catatan

Aplikasi ini dibuat untuk keperluan akademik pemenuhan tugas proyek dan demonstrasi pembelajaran Pemrograman Mobile.
